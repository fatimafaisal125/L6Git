Project title: Simple calculator
Purpose: to calculate the sum, difference, and product of two numbers taken from the user
How to run the program: Right click --> Run Code
			Enter the numbers when prompted
Example input/output:
Enter first number: 67
Enter second number: 78
Sum: 145
Difference: -11
Product: 5226
